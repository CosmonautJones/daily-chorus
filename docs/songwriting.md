# Write the hook first

Daily Chorus is a song inspired by reporting. Each verse needs one memorable detail; the chorus gives people a reason to replay it.

1. Draft two short hook ideas inside one writing pass. Pick the stronger one before expanding the song. A title people can remember and a chorus people can sing matter more than squeezing in every fact.
2. Give each headline 4–6 short lines. Use concrete images, natural speech stress, and deliberate rhymes. Keep verse density suited to the tempo. Develop each section; cut filler and strained rhymes.
3. Keep the chorus simple and consistent, with a clear emotional turn and a compact refrain that works as a 20–30 second clip. Aim for 2–3 minutes; duration is a target, not a guarantee.
4. Run one focused check before Create: facts versus fictional narrator, hook strength, line lengths/stress, proper-name pronunciation, and clean section labels. Tighten only the weak lines. Do not run an open-ended rewrite loop.
5. Save canonical readable lyrics separately from any pronunciation spellings used in the Suno lyrics field. Check tricky names before submitting; a pronunciation note in the style field alone may not resolve them.

## Suno brief

Put only sung words and simple bracketed section labels in the lyrics field. Keep the style field around 150–350 characters where practical: vocal texture/delivery, primary genre, tempo, two or three instruments, and verse-to-chorus dynamics. Distinct information beats stacks of similar adjectives. Describe an original voice and sound without artist imitation.

Example: “Warm, slightly raspy lead; conversational verses into a big group chorus. Pop-punk, 148 BPM, crunchy guitars, melodic bass, tight live drums. Clear vocal-forward mix; compact arrangement.”

On v6, inspect **Variety** and set it to zero when available to keep control of the supplied style. Record actual settings. Suno describes **Max Mode** as using more credits; standard mode remains this pilot's default. Do not add a second generation to chase a prompt target.

These are craft heuristics, not guarantees that a stochastic generator produces a hit or perfect pronunciation. Review the actual audio.

## Keep the daily run lean

Read today's state first; completed or uncertain submissions go to reconciliation. For rotation, read only recent topic/genre summaries. Search a small candidate slate, read the selected articles once, and save compact facts and URLs. Write once, check once, submit once.

Load this page during songwriting. The longer community skill files are optional references for a specific unresolved problem, not required context for every run. Rendering uses local code, a saved timeline, and existing art—no model call per frame. Default to one image per headline with gentle fades, plus a reusable chorus scene after approval. Full lyric karaoke and generated motion are optional work, not daily requirements.
